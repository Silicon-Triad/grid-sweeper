\section{Generative AI Use Declaration}

\textbf{Generative AI tools were used in this project.} The tools were Claude Code (Anthropic, model
Claude Opus 5.5 and Claude Sonnet 5.5), used by Muhammad, Mujtaba and Huzaifa, and ChatGPT (OpenAI, GPT-6), used by Ashar.
Every use was recorded in our AI use log (date, member, tool, purpose, issue).

\textbf{Purposes.}
\begin{itemize}
  \item \emph{Project setup and planning:} repository layout, continuous integration, templates, and
    the requirement list derived from the specification. Recording design decisions after the team
    chose among the options (\dec{01}--\dec{15}).
  \item \emph{Code authoring}: 
    \begin{itemize}
      \item \emph{Manual authorship:} the search functions (UCS/\astar, heuristic), the CSP solver, the environment and schedule parsers, and the comparison tooling.
      \item \emph{AI generated:} the integration, display, the notebook builder, and parts of the tests and the random file
    generator. The members who own each part reviewed it, ran the tests, and are prepared to explain it at the viva.
    \end{itemize}
  \item \emph{Commenting and DocStrings:} writing doc-strings for the functions, and classes, as well as comments in the code files for increased readability and better fog index for the evaluator's ease.
  \item \emph{Debugging and validation:} a fix to the local CI script, checks of our own and error
    input files, and test reviews.
  \item \emph{Report writing:} 
    \begin{itemize}
      \item \emph{Manual editing:} the header, footer, figure styling and alignments, tables and psuedocode styling. In addition, all content was reviewed by hand and re-written to decrease the fog index and enable better portrayal of our thoughts and considerations while designing, coding, and testing the project.
      \item \emph{AI generated:} the heuristic justification paragraph and the search-comparison
    analysis draft were AI-written. \textbf{The first report draft was completely written with Claude Code}
    from our code, decision log and measured results, and converted to LaTeX with it. The notebook's
    markdown cells and the test-run screenshots were also AI-assisted. All numbers in this report
    come from running the submitted code.
    \end{itemize}
\end{itemize}

\textbf{Responsibility.} The group reviewed and understood the implementation, the results and this
report, checked them against the specification, and takes full responsibility for the submitted
work.
