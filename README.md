# grid-sweeper — CS-323 AI CEP: Intelligent Vacuum-Cleaning Robot

A grid-world vacuum robot that schedules its cleaning tasks with a CSP
(MRV + degree, LCV, forward checking, backtracking) and navigates between them
with graph search (UCS and A* with Manhattan distance), then returns to its
charging station. Inputs: `Environment.txt` and `Schedule.txt` (formats in the
spec, `docs/spec/`).
