# Development setup

## Requirements
- Python **3.11 or newer** (`python3 --version`)
- git

## One-time setup
```bash
git clone https://github.com/Silicon-Triad/grid-sweeper.git
cd grid-sweeper
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
nbstripout --install             # strips notebook outputs on commit (.gitattributes)
```

## Jupyter
```bash
jupyter notebook notebook/
```
The notebook is generated by `python tools/build_notebook.py`; edit `src/cep/`
and the markdown sources, not the notebook directly.

## Running the checks — `tools/ci_local.sh`
```bash
tools/ci_local.sh                          # all jobs except traceability
tools/ci_local.sh lint                     # one job
tools/ci_local.sh test robustness          # several jobs
BASE_REF=origin/main tools/ci_local.sh ai-boundary
PR_BODY="$(cat body.md)" tools/ci_local.sh traceability
```
Jobs: `lint`, `test`, `robustness`, `interface`, `notebook`, `ai-boundary`,
`spec-frozen`, `traceability`. Exit code 0 = all passed. Run it before every PR.
